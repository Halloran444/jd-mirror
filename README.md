# jd-mirror

简历改写前，先照镜子。

90% 的人改简历都输在两件事：①没拆 JD 就动手，改得再好也对不上题；②缺证据就硬编，面试一问就穿。jd-mirror 把简历和 JD 逐条镜像映射：JD 每条要求 ↔ 简历每条证据，覆盖度打分、差距表、只在已有证据上动刀的改写——缺证据给"48 小时补证方案"，绝不编造。

## 背景

秋招网申 10 月上旬集中截止（浦发 10/8、中行 10/9、国家能源 10/7、中国移动多省 10/8-10/17）。海投无效简历是应届生最大的时间黑洞——多数人不是输在投得不够多，而是投得不对。

## Quick Start

对 agent 说：

> 用 jd-mirror 帮我检查这份简历和这个岗位的匹配度，JD 如下：…… 简历如下：……

它会先要齐 JD 和简历再动手，输出镜像映射表 + 覆盖度评分 + 改写版 + 按截止时间倒排的行动项。覆盖率不足 60% 时它会劝你别投——这是特性，不是 bug。

## 工作流

```
收齐材料(缺JD不开工) → 拆解JD(硬性/软性/隐藏) → 镜像映射表(JD↔证据)
        ↓                                            ↓
   网申行动项 ← 改写(只动已有证据) + ATS检查 ← 覆盖度评分(<60%劝退)
```

## 设计立场

- **证据审计，不是文案包装**：每处改写可回溯到 JD 编号
- **绝不虚构**：缺证据给补证方案，不编经历——面试是终审，造假活不过第二轮
- **敢劝退**：硬性覆盖率 <60% 明确说别投，省下的时间拿去补证或投对的地方
- **隐藏要求翻译**：读出 JD 的言外之意（"能接受轮班" = 抗压）
